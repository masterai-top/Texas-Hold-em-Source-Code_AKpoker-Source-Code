## ✨ Core Features


| Module | Feature Description |
|------|----------|
| **Lobby System** | Entry points for multiple game modes, announcements, leaderboards, in-game store |
| **Private Games/Clubs** | Private games with friends, club creation/management, league tournaments |
| **Table Logic** | Standard Texas Hold'em / Short Deck / Omaha; auto buy-in, straddle, insurance |
| **Tournament System** | MTT (Multi-Table Tournament), SNG (Sit & Go) |
| **Backend Management** | Player management, statistical reporting, game score adjustments, risk control |


## 🎮 Comprehensive Game Matrix


- **Texas Hold'em** — Classic gameplay
- **Omaha** — Four hole cards, offering more strategic variety
- **Short Deck** — Faster pace, distinct strategy
- **AOF** (All-in or Fold) — Thrilling all-in gameplay
- **MTT** (Multi-Table Tournament) — Large-scale competition
- **SNG** (Sit & Go) — Quick-start tournaments
